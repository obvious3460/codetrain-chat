# CodeTrain Chat

An unofficial Codex skill for learning programming and walking through code changes in chat. The tutor gives you one small task at a time, reviews your replies, and posts a completion message when you demonstrate the agreed goal. It follows your preferred language and has no web page or server to start.

To try it, open a Codex chat with access to this repository and ask it to use `SKILL.md` for your lesson. For example, say “Use `SKILL.md` to walk me through this commit” or “用 `SKILL.md` 带我读懂这次提交”. You can reply in chat or make an edit in your own editor and ask for feedback.

Inspired by [CodeTrain Open Skill](https://github.com/InferHaven/agent-skills/tree/main/codetrain). This version adapts its tutoring workflow for chat and does not bundle the upstream web app.
